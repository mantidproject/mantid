## Release 2.4, Released: 1 February 2013

This major release of Mantid includes a wide range of improvements and new features. A focus on single crystal diffraction in this release has allowed the team to implement some significant new tools to visualise and explore peak lists and integrated peak volumes.

Throughout the Mantid project we have fixed many of the bugs that have been reported to us. Thank you to everyone that has reported any issues to us. Please keep on reporting any problems you have, or crashes that occur to mantid-help@mantidproject.org or use this link.
