## Release 3.0, Released: 4th November 2013

This major release marks the end of version 1 of the Python API and the beginning of version 2, which has allowed us to implement some nice new features. For example the IPython interpreter is now integrated into Mantid across all platforms as the default script interpreter. This comes along with many other improvements both generally within the framework and for specific techniques.

**Mac Users Please Note:** This will be the final release that supports OS X 10.6 "Snow Leopard" or 10.7 "Lion"; from release 3.1 Mantid will require OS X 10.8 "Mountain Lion" or above.

Throughout the Mantid project we have fixed many of the bugs that have been reported to us. Thank you to everyone that has reported any issues to us. Please keep on reporting any problems you have, or crashes that occur to mantid-help@mantidproject.org or use this link.

Installation packages can be found on our [download page](http://download.mantidproject.org/), you can also download the source code from the same page or access it on [GitHub](http://github.com/mantidproject/mantid/tree/v3.0).
