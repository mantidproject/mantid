## Release 2.1, Release Due: 04 May 2012

This major release of Mantid includes a wide range of improvements and new features, we have merged the Mantid and Vates projects into a single package to simplify installation and use, as well as introducing the functionality to support live event processing and automated data reduction.

Throughout the Mantid project we have fixed many of the bugs that have been reported to us. Thank you to everyone that has reported any issues to us. Please keep on reporting any problems you have, or crashes that occur to mantid-help@mantidproject.org or use this link.

**Windows users please note:** We have changed the installer for this release, so you will need to uninstall the previous version manually using the control panel. We apologise for the inconvenience, but this should not be necessary on future versions. More details are in the {ref}`installation notes <v2.1.0-installer>`.
