# Indirect Inelastic

```{note}
These release notes were migrated from the retired Mantid wiki (archive.mantidproject.org).
```

## General

- Initial support for the VISION instrument at the SNS.
- Added some Python Algorithms that are to be road-tested over the coming weeks, with a view to adding their functionality to the interfaces as part of a future release. Note that these scripts are currently supported in the Windows 32-bit version of Mantid only:
  - ForCE
  - Jump
  - QLines
  - Quest
  - ResNorm

## Convert to Energy

- BASIS reduction tested and validated by instrument scientists.
- BASIS reduction time improved by an order of magnitude.
- Addition of an "Info Table" option for supported instruments (currently TOSCA only). This uses the new {ref}`CreateLogPropertyTable <algm-CreateLogPropertyTable>` algorithm to construct a TableWorkspace of log property data for the given runs. Instruments can be supported in the interface by making an addition of the following form to the appropriate parameter file:

```
<parameter name="Workflow.InfoTable" type="string">
    <value val="inst_abrv, run_number, user_name, run_title, hd_dur" />
</parameter>
```
