- :ref:`algm-SaveISISReflectometryORSO` can now save ORSO files using metadata from workspace history, manual inputs, or history with manual overrides. The default metadata source remains workspace history, preserving the previous behaviour for existing scripts.
- The `IncludeAdditionalColumns` property of :ref:`algm-SaveISISReflectometryORSO` no longer controls writing the Q resolution column; use `WriteResolution` to include Q resolution and `IncludeAdditionalColumns` for wavelength and incident angle columns. Behaviour of these options has been preserved for the ISIS Reflectometry GUI.
