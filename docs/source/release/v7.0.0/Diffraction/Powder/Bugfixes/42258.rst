- POLDI data recorded on the 896 detector instrument now picks up its own instrument parameter file. Previously the dated search fell through to ``POLDI_Parameters_2015.xml``, which holds the chopper ``t0`` and ``t0_const`` of the older 400 wire instrument and links to a ``detector`` component that the current geometry does not have. Every POLDI definition and parameter file has also been given an explicit ``valid-to`` date, so exactly one of each is valid at any time rather than the choice resting on a tie-break between overlapping ranges.
- ``POLDI_Definition_896.xml`` has been renamed to ``POLDI_Definition.xml``, matching the convention used by most instruments for their current definition. Scripts that name the file explicitly will need updating; those that load POLDI by instrument name or run date are unaffected.
