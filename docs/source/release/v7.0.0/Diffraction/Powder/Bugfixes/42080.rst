- :ref:`CylinderAbsorptionCW <algm-CylinderAbsorptionCW>` now scales the ``AttenuationXSection`` property from its tabulated 1.7982 Å value to the requested ``Wavelength``. Previously cross-sections provided through the properties were used unscaled, so they gave a different result to the same cross-sections set on the sample material with :ref:`algm-SetSampleMaterial` at any wavelength other than 1.7982 Å.
