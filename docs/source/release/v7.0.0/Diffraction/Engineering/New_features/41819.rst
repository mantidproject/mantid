- In ``Engineering.EnggUtils``, focusing using the ``focus_run`` method will now adjust the calibration DIFCs per detector pixel to account for an offset in the scattering volume centre-of-mass (due to sample partially illuminated within the gauge volume). This is only done when both a Sample Shape and Gauge Volume are present on the Workspace.
- The Absorption Correction tab now estimates a neutron weighted scattering centre for each detector and attaches them to the corrected data as sample logs. Where these are present, focusing adjusts the calibration DIFCs using the centre seen by each detector rather than a single centre-of-mass shared by all of them, which is what a partially immersed gauge volume requires.
