- Added a new fit function, :ref:`PoldiSidelobeGaussian <func-PoldiSidelobeGaussian>`, and a matching ``PoldiSidelobeProfile`` for Pawley refinement of POLDI autocorrelation spectra. The POLDI correlation method leaves each Bragg peak sitting in a shallow negative sidelobe, which a plain Gaussian cannot describe, so the fitted peak widths and intensities come out systematically low. The new profile models the sidelobe with a single refinable parameter - its width is fixed by the chopper speed - giving a visibly better fit to the correlation spectrum and less biased starting values for the subsequent 2D refinement.
