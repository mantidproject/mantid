- In the :ref:`Engineering Diffraction interface<Engineering_Diffraction-ref>` the :ref:`Absorption Correction tab <ui engineering correction>` now uses :ref:`algm-WeightedGaugeVolumeAbsorption` where a gauge volume is defined and the sample has no container or environment, accounting for the incident beam profile and the radial collimator. The same calculation estimates a scattering centre for each detector, attached to the corrected data as sample logs, and the :ref:`Focus tab <ui engineering focus>` uses these to adjust the calibration DIFCs per detector. This corrects the pseudo-strain seen when a gauge volume is only partially immersed in the sample, which the previous single centre of mass could not represent. Data without these logs focuses exactly as before.
