- In the :ref:`Engineering Diffraction interface<Engineering_Diffraction-ref>` the :ref:`Absorption Correction tab <ui engineering correction>` now offers a cubic gauge volume preset for every radial collimator setup known for the instrument (``0.5mmCube``, ``1mmCube``, ``2mmCube``, ``3mmCube`` and ``4mmCube`` on ENGIN-X) instead of only the 4mm cube, so that an experiment run with a narrower collimator can select the matching gauge volume rather than having to supply a custom shape file.
