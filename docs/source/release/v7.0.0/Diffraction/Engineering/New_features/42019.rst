- In the :ref:`Engineering Diffraction interface<Engineering_Diffraction-ref>` the :ref:`Absorption Correction tab <ui engineering correction>` now estimates a neutron weighted scattering centre for each detector whenever an absorption correction is calculated, and attaches them to the corrected data as sample logs. Where these logs are present, the :ref:`Focus tab <ui engineering focus>` adjusts the calibration DIFCs using the centre seen by each detector rather than a single centre-of-mass shared by all of them, which is what a gauge volume only partially filled by the sample requires.
