- Added the :ref:`FindUBFromConventionalCell <algm-FindUBFromConventionalCell>` algorithm, which determines a UB matrix (crystal orientation) from unindexed peaks and the known conventional-cell lattice parameters and centering. It reduces the cell to its primitive setting, searches the lab-frame axis directions that best align the peak Q-vectors, and converts the result back to the conventional setting. It supports primitive and centered (A, B, C, I, F, R) lattices and works with only a few peaks.
