- In the :ref:`ISIS SANS GUI <ISIS_Sans_interface_contents>`, reloading a batch file saved from the GUI now restores everything that was entered. The sample shape and the ``Options`` column are now saved to the file. When the file is loaded, the ``Multi-period``, ``Sample Geometry`` and ``Scaled Background Subtraction`` columns and checkboxes are switched on if the file uses them. The ``Multi-period`` checkbox also no longer switches itself off when a table cell is edited, and the ``Options`` column no longer gains an extra comma each time a row is edited.
