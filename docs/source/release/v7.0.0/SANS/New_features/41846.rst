- :ref:`BatchReduce <SANSScriptingBatchReduce>` function on the :ref:`SANS ISIS Command Interface<ScriptingSANSReductions>` now has a `clean_up_ads` parameter to automatically delete all non-reduced workspaces (optimization, raw and transmission) from the ADS at the end of a Batch Reduction.
