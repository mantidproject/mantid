- Workspaces now provide ``getLabFrameSampleShape``, returning the sample shape as it sits in the lab frame, rotated by whatever part of the workspace's goniometer rotation the shape does not already carry. A shape may be stored in its own frame or already rotated into the lab frame - :ref:`algm-CopySample` bakes the goniometer in, while :ref:`algm-SetGoniometer` alone leaves the shape untouched - so rotating by the goniometer directly risks turning an already-rotated shape a second time. The workspace's own sample is left unchanged.
- Sample shapes now expose ``getAppliedRotation``, the goniometer rotation baked into the shape. This reports which frame the shape is in, not every rotation it has ever had: definition-frame rotations such as the ``XDegrees`` properties of :ref:`algm-LoadSampleShape`, ``rotate-all`` tags and :ref:`algm-RotateSampleShape` are excluded, so the identity means the shape is expressed in its own frame however much its definition has been rotated within that frame.
