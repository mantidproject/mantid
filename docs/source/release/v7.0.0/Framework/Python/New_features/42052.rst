- Workspaces now provide ``getLabFrameSampleShape``, returning the sample shape as it sits in the lab frame, rotated by whatever part of the workspace's goniometer rotation the shape does not already carry. A shape may be stored in its own frame or already rotated into the lab frame - :ref:`algm-CopySample` bakes the goniometer in, while :ref:`algm-SetGoniometer` alone leaves the shape untouched - so rotating by the goniometer directly risks turning an already-rotated shape a second time. A shape that offers no way to express a rotation, such as the flat plate ``MeshObject2D``, is taken to be defined in the frame it is meant to be used in and is returned unchanged with a warning, even when the workspace has an outstanding goniometer rotation - so the result is not necessarily in the lab frame. The workspace's own sample is left unchanged.
- Sample shapes now expose ``getAppliedRotation``, the goniometer rotation baked into the shape. This reports which frame the shape is in, not every rotation it has ever had: definition-frame rotations such as the ``XDegrees`` properties of :ref:`algm-LoadSampleShape`, ``rotate-all`` tags and :ref:`algm-RotateSampleShape` are excluded, so the identity means the shape is expressed in its own frame however much its definition has been rotated within that frame.
