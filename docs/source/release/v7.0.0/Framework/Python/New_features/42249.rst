- Workspaces now provide ``getLabFrameSampleShape``, returning the sample shape as it sits in the lab frame, rotated by whatever part of the workspace's goniometer rotation the shape does not already carry. The workspace's own sample is left unchanged. A flat-plate shape offers no way to express a rotation, so it is taken to be defined in the frame it is meant to be used in and returned unchanged with a warning.
- Sample shapes now expose ``getAppliedRotation``, the goniometer rotation baked into the shape. This says which frame the shape is in, not every rotation it has ever had: rotations that re-express the shape within its own frame - the ``XDegrees`` properties of :ref:`algm-LoadSampleShape`, ``rotate-all`` tags and :ref:`algm-RotateSampleShape` - are excluded, so the identity means the shape is in its own frame however much its definition has been rotated within that frame.
