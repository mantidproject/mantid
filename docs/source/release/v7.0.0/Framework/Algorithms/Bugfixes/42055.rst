- :ref:`algm-EstimateScatteringVolumeCentreOfMass` no longer rotates the sample shape twice when the shape already carries the goniometer rotation. Shapes now report the rotation baked into them and only the remainder is applied, so a sample oriented with :ref:`algm-SetGoniometer` and one baked by :ref:`algm-CopySample` give the same centre of mass. Results change for workspaces whose sample was copied onto an oriented workspace - in a scanned gauge volume test case the reported centre moved by over 3 mm.
- A shape now reports only a goniometer rotation as having been baked in, not every rotation it has ever been given. Rotations that re-express a shape within its own frame - the ``XDegrees``, ``YDegrees`` and ``ZDegrees`` properties of :ref:`algm-LoadSampleShape` and :ref:`algm-LoadSampleEnvironment`, the ``rotation`` element of a sample environment definition, and :ref:`algm-RotateSampleShape` - are excluded. A mesh sample loaded with a rotation onto a workspace carrying a goniometer previously reported both combined, which left neither the whole goniometer rotation nor none of it outstanding.
- :ref:`algm-RotateSampleShape` no longer applies the workspace's goniometer in addition to the rotation it was given, and successive calls on a CSG shape now compose rather than the later replacing the earlier. Mesh shapes always composed, so the two shape types now agree. Scripts that relied on the replacing behaviour of successive calls will need updating.
- :ref:`algm-CopySample` now leaves the copied shape rotated by exactly the destination workspace's goniometer whatever frame the source was in. Previously a mesh shape that already carried that rotation was turned through it a second time, and for a CSG shape any rotation of the shape within its own frame was discarded. That preserved rotation is a change in behaviour for a shape defined with a ``rotate-all`` tag or rotated with :ref:`algm-RotateSampleShape` before being copied.
- :ref:`algm-SetSample` no longer sets the material on a sample environment's shared shape definition, which changed it for every later call in the session.
- :ref:`algm-RotateSampleShape` and :ref:`algm-TranslateSampleShape` no longer alter the sample of every other workspace that shares the shape. A workspace copied or cloned from another holds the very same mesh, and both algorithms moved its vertices where they lay, so rotating or translating one sample silently moved the others too. They now replace the shape with a moved copy, as they have always done for CSG shapes. Mesh samples only.
