- Absorption and scattering corrections now account for the sample's orientation instead of silently ignoring it. :ref:`algm-MonteCarloAbsorption`, :ref:`algm-PaalmanPingsAbsorptionCorrection`, :ref:`algm-DiscusMultipleScatteringCorrection`, :ref:`algm-MultipleScatteringCorrection`, :ref:`algm-XrayAbsorptionCorrection` and the single-path mode of :ref:`algm-AddAbsorptionWeightedPathLengths` all traced lab-frame rays through a sample shape that was still in its own frame, so a workspace oriented with :ref:`algm-SetGoniometer` alone was corrected as though the sample had never been turned. The gauge volume, the beam and the detectors are all described in the lab frame, so the sample is now moved there too. Results are unchanged for a workspace with no goniometer, and for one whose shape was baked by :ref:`algm-CopySample` - both already described the sample in the lab frame. Only the previously incorrect case changes, and the two ways of orienting a sample now give the same answer.
- The Monte Carlo mode of :ref:`algm-AddAbsorptionWeightedPathLengths` cannot yet do this, because its interaction volume and beam profile are built once while the goniometer rotation varies from peak to peak. It now warns when that case arises rather than returning numbers computed with the sample in the wrong place.
