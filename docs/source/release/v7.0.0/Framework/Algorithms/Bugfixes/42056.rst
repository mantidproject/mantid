- :ref:`algm-EstimateScatteringVolumeCentreOfMass` now weights each raster element by its volume when averaging their positions. :ref:`algm-Rasterize` does not divide every shape into elements of equal volume - a cylinder becomes annular segments whose volume grows with radius - so an unweighted average was biased towards the more finely divided region near the axis. No result reachable today changes: a cylinder rasterised without a gauge volume accepts every element and so is symmetric about its axis either way, and the gauge volume path dices a bounding box into elements of equal volume. The weighted centroid is the one that matches the volume integral the raster describes, so this stops being an equivalence as soon as unequal elements are clipped asymmetrically.
