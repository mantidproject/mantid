- New algorithm :ref:`algm-WeightedGaugeVolumeAbsorption` calculates attenuation factors in the same way as :ref:`algm-AbsorptionCorrection`, but weights each integration element by the spatial resolution function - the incident beam profile, the attenuation, and the radial collimator acceptance - rather than treating every element as scattering equally. It can additionally report, per detector, the neutron weighted scattering centre of the volume that detector sees, which is displaced from the geometric centre when a gauge volume is only partly immersed in the sample. With no beam profile and no calibrated collimator it reduces exactly to :ref:`algm-AbsorptionCorrection`.
