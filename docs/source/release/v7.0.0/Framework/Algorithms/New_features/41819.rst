- Algorithm :ref:`algm-EstimateScatteringVolumeCentreOfMass` now accepts an option, `UseNeutronWeightings`, to weight the illuminated volume by the spatial resolution function - incident beam profile, attenuation, and collimator acceptance - instead of treating every volume element equally. The resulting centre of mass differs per detector, and these can be output as a table with the new `DetectorScatteringCentres` property.
- Algorithm :ref:`algm-SetBeam` now accepts optional `HorizontalDivergence`, `VerticalDivergence` and `SlitDistance` geometry flags, describing a beam whose edges blur with distance from the defining slit rather than one that is perfectly collimated.
