- :ref:`algm-FitPeaks` now has ``StrictConvergence`` flag, which decides whether fits which have finished due to the parameter step size passing below the stopping threshold should be considered as successful - default is ``True`` to match previous behaviour.
- :ref:`algm-FitPeaks` now accepts ``Unweighted least squares`` cost function.
- :ref:`algm-FitPeaks` now has ``PositionToleranceMode`` input which controls ``PositionTolerance`` behaviour. Default is ``Check`` which maintains previous behaviour of the positional tolerance being checked after the fit and discarding any fits outside tolerance. This parameter enables ``Constrain`` mode, which will instead apply the tolerances as constraints on the fit. ``Constrain`` mode requires ``ConstrainPeakPositions`` be disabled.
- :ref:`algm-FitPeaks` now has ``CalculateUnconstrainedErrors`` which controls whether the errors for fits should be recomputed after the fit, without the constraints applied. Default is ``False``.
- :ref:`algm-FitPeaks` now has ``PositionToleranceFractional`` which controls whether the ``PositionTolerance`` should be treated as a fraction of the peak window (``True``) or as an absolute value (``False``, default).
