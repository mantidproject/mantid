- In the new Instrument View, workspaces whose x axis units cannot be converted no longer cause errors. This covers workspaces with no units at all, workspaces with a unit such as a label or degrees, and workspaces whose instrument has no sample or source position. Unit selection is disabled for these workspaces, which are shown in their own x values, and everything else continues to work as normal.
- In the new Instrument View, summing the selected spectra no longer fails for units in which the spectra cannot share a common binning, such as momentum transfer for a detector in the path of the beam. The spectra are plotted unsummed in this case.
