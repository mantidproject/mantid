## Released: 03 Feb 2012

This major release of Mantid includes a wide range of improvements and new features, including a much improved Python interface and the ability to float graph windows anywhere on your desktop. However perhaps most importantly this version has been through an extended and rigorous testing process and has been validated by several instrument scientists to give us the best release of Mantid yet.

This release is the result of four months of consistent hard work of the entire Mantid development team, and I would like to thank them and the scientists from [ISIS](http://www.isis.stfc.ac.uk/) and the [SNS](http://neutrons.ornl.gov/) who helped test this release.

Throughout the Mantid project we have fixed many of the bugs that have been reported to us. Thank you to everyone that has reported any issues to us. Please keep on reporting any problems you have, or crashes that occur to mantid-help@mantidproject.org or use this link.
