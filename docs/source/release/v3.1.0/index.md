## Release 3.1, Released: 7th February 2014

The release over christmas is always a smaller release due to the holidays and this was compounded this time with several runs of the training courses as well as the Scientific Steering Committee and developer workshop meetings. However that did not stop us adding lots of important improvements throughout Mantid, particularly for plotting, reflectometry, and the addition of support for Integration reports for single crystal diffraction data.

**Mac Users Please Note:** From this release Mantid will require OS X 10.8 "Mountain Lion" or above. If for some reason you cannot update you may continue to use Mantid v3.0.

Throughout the Mantid project we have fixed many of the bugs that have been reported to us. Thank you to everyone that has reported any issues to us. Please keep on reporting any problems you have, or crashes that occur to mantid-help@mantidproject.org or use this link.

Installation packages can be found on our [download page](http://download.mantidproject.org/) or [sourceforge](https://sourceforge.net/projects/mantid/files/3.1/), you can also download the source code from the same page or access it on [GitHub](https://github.com/mantidproject/mantid/releases/tag/v3.1.0).
