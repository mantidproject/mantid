### Are any changes included in the release that are not accounted for above?

No.

### Is the collective effect of the changes acceptably low risk?

Yes, the vast majority are small (in terms of the amount of code changed) and in very well-isolated areas. The most pervasive is the change under ticket 4815, which has been thoroughly examined via inspection and manual and automated testing. The changes to instrument definition files in some cases will have a large impact for the instruments affected, but should have been implemented in conjunction with instrument scientists, who will have agreed the changes.
