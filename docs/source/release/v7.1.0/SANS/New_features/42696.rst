- :ref:`SaveSESANS <algm-SaveSESANS>` now also writes the sample changer position(s) to the file header, taken from the ``SamplePos`` log within the selected time range or from the new ``SamplePosition`` property. The run numbers of the blank and of the sample and blank transmission measurements can be added with the new ``BlankRunNumber``, ``SampleTransmissionRunNumber`` and ``BlankTransmissionRunNumber`` properties.
