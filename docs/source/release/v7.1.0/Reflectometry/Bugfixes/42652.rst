- The model descriptions entered in the ``Model`` column of the search results table on the Runs tab of the :ref:`ISIS Reflectometry <interface-isis-refl>` interface are now saved to ORSO files. Each dataset in the file is given the model for its run, unless a model is entered on the Save tab, which then applies to all the datasets.
- The ``ModelDescription`` property of :ref:`algm-SaveISISReflectometryORSO` has been replaced by ``ModelDescriptions``, which takes one model description for each workspace in ``WorkspaceList``. To use the same model for every workspace, repeat it for each entry. Model descriptions are now ignored when ``MetadataSource`` is ``History``, because the model is not stored in the workspace history. Use ``HistoryWherePossible`` or ``Manual`` to include a model.
