- :ref:`LoadMuonNexusV2 <algm-LoadMuonNexusV2>` now stores the ``FirstGoodData`` sample log relative to time zero when ``CorrectTime`` is true (the default), consistent with :ref:`LoadMuonNexus <algm-LoadMuonNexus>`. When ``CorrectTime`` is false, the log keeps the absolute first good time. Previously it stored the absolute time, which made :ref:`CalMuonDetectorPhases <algm-CalMuonDetectorPhases>` start its fit too late when ``FirstGoodData`` was left blank.
