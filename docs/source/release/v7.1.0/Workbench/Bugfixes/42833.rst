- In the :ref:`Show Sample Shape <Mesh_Plots>` plot, when the workspace has a goniometer rotation, for example from :ref:`algm-SetGoniometer`, the sample is now drawn where the goniometer puts it, matching the lattice vectors drawn beside it. Previously it was drawn unrotated unless :ref:`algm-CopySample` had rotated the shape itself. The container, and any other part of the sample environment mounted on the goniometer, is turned with it.
