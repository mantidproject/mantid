- The new Instrument View no longer copies the workspace to colour the detectors, or converts it when the integration range is in another unit, which reduces its memory use, especially for event workspaces. For histogram data with the integration range in momentum transfer, whose bins run in the opposite order to time-of-flight, a bin only partly inside the range is now counted at the low end of the range rather than the high end, so detector counts can differ slightly from before.
