- New class :class:`~mantid.api.SpectraUnitConverter`, made from a workspace and a unit, which can be passed as ``unitConverter`` to ``getIntegratedCountsForWorkspaceIndices`` and ``getXMinMax`` on :class:`~mantid.api.MatrixWorkspace`. The integration range, or the returned X range, is then in that unit, much as if :ref:`ConvertUnits <algm-ConvertUnits>` had been run first, but without converting or copying the workspace.
