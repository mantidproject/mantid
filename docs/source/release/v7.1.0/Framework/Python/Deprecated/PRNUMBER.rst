- ``MatrixWorkspace.getDetector()`` and the :class:`~mantid.geometry.DetectorGroup` methods ``getDetectorIDs()`` and ``getNameSeparator()`` are deprecated and now raise a ``DeprecationWarning``. Use the workspace's ``spectrumInfo()``, ``detectorInfo()`` and ``componentInfo()`` instead; for example, ``spectrumInfo().getSpectrumDefinition(i)`` gives the detectors of a spectrum. See :ref:`InstrumentAccessLayers`.
