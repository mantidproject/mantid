- In :ref:`algm-MonteCarloAbsorption`, :ref:`algm-DiscusMultipleScatteringCorrection`, :ref:`algm-MultipleScatteringCorrection`, :ref:`algm-XrayAbsorptionCorrection`, :ref:`algm-AbsorptionCorrection`, :ref:`algm-CuboidGaugeVolumeAbsorption`, :ref:`algm-CylinderAbsorption` when no cylinder dimensions are given, and :ref:`algm-AddAbsorptionWeightedPathLengths` with ``UseSinglePath``, when the sample is oriented by a goniometer, for example with :ref:`algm-SetGoniometer`, the correction now uses the sample in its rotated position. Previously the goniometer rotation was ignored and the sample corrected as though unrotated, so rerun corrections on such workspaces. Results are unchanged for a workspace with no goniometer rotation, or whose sample shape was rotated by :ref:`algm-CopySample`. A sample in a container or sample environment is still used as defined, with a warning, because the environment is not currently rotated by the goniometer. So :ref:`algm-PaalmanPingsAbsorptionCorrection`, which always has a container, is unchanged, as is :ref:`algm-MayersSampleCorrection`.
- In :ref:`algm-AddAbsorptionWeightedPathLengths`, when ``UseSinglePath`` is off and a peak has a goniometer rotation that the sample shape does not, a warning now says the Monte Carlo calculation ignores that rotation. Rotate the shape with :ref:`algm-CopySample`, or set ``UseSinglePath``, to account for it.
- In :ref:`algm-EstimateScatteringVolumeCentreOfMass`, when the sample shape was rotated by :ref:`algm-CopySample` onto a workspace with a goniometer rotation, the shape is no longer rotated a second time. Previously the centre of mass could be several millimetres out, so rerun any that matter.
- In :ref:`algm-RotateSampleShape`, the shape is now rotated by only the rotation given, and successive calls on a CSG shape add together rather than the later replacing the earlier. Previously the workspace's goniometer rotation was applied as well; the corrections that use the shape now apply it instead. Update scripts that relied on a later call replacing an earlier one.
- In :ref:`algm-CopySample`, the copied shape is now rotated by exactly the destination workspace's goniometer rotation. Previously a mesh shape already rotated by a goniometer, for example by :ref:`algm-LoadSampleShape`, was rotated a second time, and a CSG shape lost any rotation from a ``rotate-all`` tag or from :ref:`algm-RotateSampleShape`.
- In :ref:`algm-SetSample`, when the sample environment has a fixed sample shape from an STL file, setting the sample no longer changes that shape for later calls in the session.
- In :ref:`algm-RotateSampleShape` and :ref:`algm-TranslateSampleShape`, when the sample is a mesh, other workspaces sharing the sample, such as clones, are no longer rotated or translated too.
