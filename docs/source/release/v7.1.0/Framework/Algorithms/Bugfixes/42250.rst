- In a :ref:`shape definition <HowToDefineGeometricShape>`, when a cuboid given by four corner points, a cone or an infinite cone is rotated by ``rotate-all`` or the goniometer, the shape is now rotated, and both cones now honour their own ``rotate`` tag too. Previously these shapes stayed as defined. This changes, for example, a flat plate from :ref:`algm-SetSample` on a workspace with a goniometer rotation, any of these shapes turned with :ref:`algm-RotateSampleShape`, and the cuboid :ref:`algm-FlatPlateAbsorption` leaves on a workspace once :ref:`algm-CopySample` copies it onto a rotated one. Rerun absorption corrections made on such samples.
- In a :ref:`shape definition <HowToDefineGeometricShape>`, when a sphere, cylinder or hollow cylinder is rotated, the random points that Monte Carlo corrections such as :ref:`algm-MonteCarloAbsorption` scatter from now follow the rotation. Previously some of these points stayed where the shape was defined, outside the rotated sample.
- In a :ref:`shape definition <HowToDefineGeometricShape>`, a cone's bounding box, volume, solid angle and drawing in the :ref:`legacy Instrument Viewer <LegacyInstrumentViewer>` now describe the cone where it is. Previously the bounding box and drawing were mirrored through the tip and the solid angle left out the cone's sloping side, so a cone shape had a volume of zero and :ref:`algm-MonteCarloAbsorption` failed on a cone-shaped sample.
