- In a :ref:`shape definition <HowToDefineGeometricShape>`, when a cuboid given by four corner points, a cone or an infinite cone is rotated by ``rotate-all`` or the goniometer, the shape is now rotated; a cone's own ``rotate`` tag is now honoured too. Previously these shapes stayed as defined. This changes, for example, a flat plate from :ref:`algm-SetSample` on a workspace with a goniometer rotation, any of these shapes turned with :ref:`algm-RotateSampleShape`, and the cuboid :ref:`algm-FlatPlateAbsorption` leaves on a workspace once :ref:`algm-CopySample` copies it onto a rotated one. Rerun absorption corrections made on such samples.
- In a :ref:`shape definition <HowToDefineGeometricShape>`, when a sphere, cylinder, hollow cylinder or cone is rotated, its bounding box, its plot and the random points that Monte Carlo corrections such as :ref:`algm-MonteCarloAbsorption` scatter from now follow the rotation. Previously they stayed where the shape was defined, so some scattering points could fall outside the rotated sample, and a rotated cone's volume could be wrong. Cuboids and hexahedra were already correct.
