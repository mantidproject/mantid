- In :ref:`algm-MonteCarloAbsorption`, :ref:`algm-PaalmanPingsAbsorptionCorrection`, :ref:`algm-MultipleScatteringCorrection`, :ref:`algm-DiscusMultipleScatteringCorrection` and :ref:`algm-AbsorptionCorrection`, when the sample sits in a container or :ref:`sample environment <SampleEnvironment>` and the workspace has a goniometer rotation, for example from :ref:`algm-SetGoniometer`, the sample and its container now turn together. Previously both were used unrotated, or, for a sample turned by :ref:`algm-CopySample` or loaded from a 3MF file with :ref:`algm-LoadSampleEnvironment`, the sample was turned inside an unturned container. Rerun corrections on such workspaces.
- In :ref:`sample environment definitions <SampleEnvironment_goniometer>` and :ref:`algm-LoadSampleEnvironment`, each part of an environment can now say whether it turns with the sample, with an ``ongoniometer`` attribute or the ``OnGoniometer`` property. By default only the container does, so mark the other parts of, say, a pressure cell that is turned as a whole.
