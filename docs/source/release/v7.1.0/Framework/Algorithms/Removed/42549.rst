- The algorithm ``IntegratePeaksMD v1`` was deprecated in :ref:`Release 6.13.0 <v6.13.0>` and has now been removed. Use :ref:`IntegratePeaksMD v2 <algm-IntegratePeaksMD-v2>` instead.
