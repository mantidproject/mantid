- :ref:`algm-ConvertHFIRSCDtoMDE` now accepts a WorkspaceGroup of detector-space workspaces, such as several HB3A scans from :ref:`algm-HB3AAdjustSampleNorm` with ``OutputType="Detector"``. Each scan is converted with its own goniometer settings and wavelength. The result is a WorkspaceGroup named as in :ref:`algm-HB3AAdjustSampleNorm`, or, with the new ``MergeInputs`` property, a single merged MDEventWorkspace.
- :ref:`algm-ConvertHFIRSCDtoMDE` now uses the ``wavelength`` sample log of the input workspace when present, as :ref:`algm-HB3AAdjustSampleNorm` does, and the ``Wavelength`` property only when the log is missing; a warning is logged when the two values differ. Previously the ``Wavelength`` property was always used. ``Wavelength`` can now hold one value per member of a WorkspaceGroup.
