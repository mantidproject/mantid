- New algorithm :ref:`algm-HFIRSCDSubtractBackground` subtracts a background measured at a single goniometer angle from WAND and DEMAND data in detector space, before the conversion to Q-sample. The background is scaled to the time or monitor counts of each goniometer angle of the sample, and the uncertainties are propagated. The sample can be a WorkspaceGroup of scans, the subtraction can be done in place to save memory, and an ungrouped background can be grouped to match a sample loaded with pixel grouping.
- :ref:`algm-LoadWANDSCD` now returns raw counts by default: ``NormalizeData`` defaults to ``False`` instead of ``True``. Scripts that provide vanadium data and rely on the previous default to normalize the data must now set ``NormalizeData=True``. The algorithm also rejects inputs where the vanadium data would be missing or unused: ``NormalizeData=True`` or ``OutputNormalizationWorkspace`` without vanadium data, and vanadium data with ``NormalizeData=False`` and no ``OutputNormalizationWorkspace``. Previously these inputs were accepted, and the vanadium data or the normalization request was ignored.
- :ref:`algm-MDNorm` now rejects ``BackgroundWorkspace`` for monochromatic single crystal diffraction, that is, when ``MonoSCDNormalizationWorkspace`` is given or ``InputWorkspace`` comes from WAND or DEMAND, with a message that refers to :ref:`algm-HFIRSCDSubtractBackground`. The background of WAND and DEMAND data is to be subtracted in detector space, before the conversion to Q-sample with :ref:`algm-ConvertHFIRSCDtoMDE`.
