- :ref:`algm-LoadWANDSCD` now returns raw counts by default: ``NormalizeData`` defaults to ``False`` instead of ``True``. Scripts that provide vanadium data and rely on the previous default to normalize the data must now set ``NormalizeData=True``. The algorithm also rejects inputs where the vanadium data would be missing or unused: ``NormalizeData=True`` or ``OutputNormalizationWorkspace`` without vanadium data, and vanadium data with ``NormalizeData=False`` and no ``OutputNormalizationWorkspace``. Previously these inputs were accepted, and the vanadium data or the normalization request was ignored.
