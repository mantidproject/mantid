- :ref:`algm-IntegratePeaksShapeMD` can now normalize intensities by flux and solid angle, in the same units as :ref:`algm-MDNorm` but without binning, using the new *SolidAngleWorkspace* and *FluxWorkspace* properties. With *ProfileFit* the fit accounts for the exposure across each peak, including peaks partly covered by masked detectors, and the new *AdjustShape* option refines the shape of each strong enough peak (with *AdjustCenter*, also its center, which may move up to *MaxCenterShift* standard deviations to reach a peak predicted off its true position). The new *OutputDiagnosticsWorkspace* flags peaks whose coverage is incomplete.
