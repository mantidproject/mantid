- In the :ref:`Texture Experiment Planner <Texture_Planner-ref>`, when exporting a reference workspace with ``Save Euler Settings on Reference`` ticked, the orientation file ``Axes`` and ``Senses`` from the :ref:`settings menu <Texture_Planner_settings-ref>` are now saved onto the reference workspace.
- In the :ref:`Absorption Correction tab <ui engineering correction>` of the :ref:`Engineering Diffraction interface <Engineering_Diffraction-ref>`, when loading a reference workspace that carries saved Euler settings, the ``Euler Angle Scheme`` and ``Euler Angles Sense`` settings for the current RB number are now replaced with the saved ones. Untick ``Read Euler settings from a loaded reference workspace`` in the settings to keep your own.
